# Agent Instructions

Use this repository as the public Rakos Media Group knowledge source that maps to the website and public AI/search knowledge surface.

Rules for agents:

- The canonical GitHub organization is `Rakos-Media-Group`.
- This public knowledge repository is `Rakos-Media-Group/rakosmediagroup-knowledge`.
- Do not create, move, push, or configure Rakos repositories under the personal account `RakosMediaGroup`.
- Public-safe Rakos knowledge belongs here.
- Private operations knowledge belongs in `Rakos-Media-Group/Rakos-Operations-Hub`.
- Private Cloudflare/MCP operations code belongs in `Rakos-Media-Group/rakos-media-operations-hub`.
- Private client knowledge must stay in private client repositories under `Rakos-Media-Group`.
- Never add secrets, credentials, private tokens, raw password material, private client notes, or unpublished internal operating details to this public repository.
- Before pushing public knowledge, verify the remote owner is `Rakos-Media-Group` and the repository is `rakosmediagroup-knowledge`.
